# 人物档案

> 人名统一写法（便于英译）：凯尔 Kyle / 胡昊（熊猫）Hu Hao "Panda" / 瑞安·马尔科维奇 Ryan Markovich（熟人叫马尔科）/ 奥尼克斯 Onyx / 老格 Old Greg / 乌苏拉 Ursula / 朱利安 Julian / 瓦伦丁 Valentin / 布莱斯 Bryce / 塔莉娅 Talia / 德克斯 Dex / 卡西安 Cassian / 德韦恩 Dwayne

## 主角

### 凯尔（李凯尔，编号 2B-1747）
- **年龄/职业**：十八岁，高中生 → 刚升格的半神，负债人。
- **外貌特征**：瘦，驼背，套头衫大两号，头发乱；骨相好看，混血感，熊猫说他“是个精灵，就是脏了点”。右手虎口有一道小时候摔的疤。
- **性格核心**：表面木讷、能忍、懒得反抗；内里聪明、嘴毒、观察力极强，对数字和尺寸敏感。压力过载时会犯困（“不吃压力了”）。
- **核心价值观**：别连累别人；账要看得见。
- **最大恐惧**：再背一笔自己看不懂的债；害死身边的人。
- **致命缺陷**：一旦觉得“反正已经完了”，就会放弃挣扎；一旦尝到甜头，又容易一口气推到底，不留余地（第七、八章的杠杆悲剧由此而来）。
- **内心渴望**：一个属于自己的地方（存档、驾驶舱、宇宙），以及一个不会离开的朋友。
- **说话风格**：短句，冷幽默，损人不留情；紧张时用游戏梗理解世界（存档、新手教程、支线、爆仓）。口头反应多为“行吧”“嗯哼”。
- **技能**：巴西柔术底子，招牌裸绞；打游戏几千小时，开飞行类游戏手感极好。
- **背景故事**：家道中落，父母离婚，父亲酗酒；哥哥李凯文让他以法定代表人身份签字，留下五百万日元（折合三千万美元）的债后失联；母亲改嫁武田家，只负担学费。在学校是“眠龙”，被霸凌。十一周的怪梦让他无意中向禁区广播了坐标，导致β-1335宇宙簇群十万个宇宙被毁，自己的宇宙也被注销。他在残骸中活下来，继承了两万亿星系的算筹，完成升格。
- **升格后的状态**：投影体（人形，可被打碎、立刻复原）+ 化神舰本体（四对翼，轻型状态全长六千三百公里）。第五章前没有自己的宇宙，第五章获得“新存档”，第八章失去。**量级高，位格低**，并背着超级农场级的债。
- **MBTI**：INTP

### 瑞安·马尔科维奇（马尔科）
- **身份**：高阶半神（真实位格不明），凯尔的担保人、契约方、教练兼债主。过去“作威作福”过，后来出过“那件事”，地位下滑，急需翻身。
- **外貌特征**：高，精壮，乱糟糟的络腮胡，黑色旧外套，一双大手。
- **性格核心**：毒舌、懒散、精于算计，像推销员也像赌徒；关键时刻露出真心（讲回收酷刑时）。
- **说话风格**：比喻刻薄（“像看猩猩读莎士比亚”），爱用“小子”，爱说“好问题，我以后回答你”。
- **动机**：拿凯尔下注翻身；对凯尔的真实来历知道得比他说的多（老格认出的“他”）。
- **致命缺陷**：习惯把人当筹码，事后再补偿；经常不在场。

## 反派

### 乌苏拉（法庭里那滩咕噜声）
- **身份**：半神，控制着一个克苏鲁式宇宙，宇宙的形态反过来改造了他的投影体和化神舰，令人看一眼就反胃。舰队几百艘。
- **欲望**：把凯尔当“基质”展开，做成可持续产出的温床。
- **说话风格**：咕噜声，只有马尔科能翻译；战斗中能直接把“饥饿”灌进对手脑子里。
- **结局**：第四章吸收凯尔算筹时“食物中毒”，被凯尔连同本体和宇宙一起轰杀。

### 瓦伦丁
- **身份**：高位格半神，属于曾用凯尔坐标袭击β-1335的那一方。
- **外貌**：投影体是穿灰色西装的中年男人，干净得像刚熨过；化神舰是白色长矛形。
- **性格**：礼貌、傲慢、相信位格决定一切；说话像律师宣读条款。
- **目的**：趁马尔科不在，来取“钥匙”（凯尔），顺便吞掉朱利安的宇宙。
- **结局**：第五章被凯尔用事件武器重创投影体（伤及本体），再被朱利安以宇宙级能量击杀。

### 卡西安
- **身份**：第七、八章敌方部队指挥官，位格和量级略胜五人小队总和。冷静，打消耗战。

## 配角

### 胡昊（熊猫）
- 凯尔死党，一米六八，九十一公斤，黑框大眼镜；技术宅，写过绕过年龄验证的脚本。耦合度9.4，被奥尼克斯接走，进莱因哈特学院读“世界工程师序列”。前八章只在回忆和结尾出现。

### 奥尼克斯
- 银甲巨人，三米多，声音像播音员。β级案件独任法官。死板，不会算账，与马尔科有旧怨。

### 老格
- 造舰师（锻造化神舰），矮小秃顶，工作服配鲜艳领带，二手车行老板气质。认出凯尔像“他”，被马尔科压下。心软，嘴碎。

### 朱利安
- **身份**：低位格半神，独立宇宙主人（单地球宇宙，科技水平约2030年代），也是出租房东。
- **外貌**：投影体胖胖的，T恤上印着游戏logo，拖鞋，头发油。
- **性格**：宅、怂、热心、说话快，懂规矩懂门道，是凯尔第一个真正的朋友。量级远低于凯尔。
- **口头禅**：“这不合规矩……但是可以。”
- **结局**：第八章被凯尔的杠杆连带爆仓，神魂俱灭。

### 布莱斯 / 塔莉娅 / 德克斯（三人小团体）
- 同队三位半神，popular kid气质：漂亮、自信、彼此互相捧场，对凯尔和朱利安居高临下。
- **布莱斯**：队长气质，四分卫式人物，化神舰金色，五万艘。
- **塔莉娅**：话少，冷，观察力好；舰队四万艘。第八章收留凯尔租住（“没有朋友价”）。
- **德克斯**：嗓门大，爱起外号（叫凯尔“地下室”），三万五千艘。

### 德韦恩
- 凯尔在“新存档”宇宙里请的篮球教练，退役球员，不知道自己在教一个神；嘴很损。
